# PROYECTOIII-SMARTVIAVLC
Traffic preditcion of certain areas of Valencia, taking into account climatological factors and events.
This is project developed for the subject PROYECTO III. 

- The notebook model2.ipynb has the code that correspond to the final report.
- The notebook ML.ipynb shows the model experimentation that we did. 
- The other notebooks that are left are data preparation and EDA that we did at the start of the project.

dataset_final.zip are the data that will be used in the models.
